# Alçadas do Grupo PFB

Proposta de níveis de aprovação (alçadas) das operações internas do Grupo Pra Frente Brasil, para avaliação dos sócios.

A página tem a régua de níveis, um simulador, a matriz por tipo de operação, casos práticos e os parâmetros em decisão. Minuta para discussão, de 30/09/2026, preparada pela Diretoria Financeira e de Controladoria.
